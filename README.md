# Vector-manipulation-and-delay-system
4 bit vector manipulation and delay system in digital.exe

# Features
Input: 4-bit vector (X) and 2-bit control signals (a, b).
Operations:a=0, b=0: No output transfer.
           a=0, b=1: Direct vector transfer.
           a=1, b=0: Single right rotation.
           a=1, b=1: Double right rotation.
Delay: Output delayed using D flip-flops.
Implementation: Logic gates, multiplexers, and shift registers.
